# MetaAg_2o


## Mode
MetaAg 2o has two modes, 1. Personal Usage, 2. Enterprise Usage. 
Personal mode uses an Airtable structured datasheet as a backend. Simply in the code, add your base ID and Table name to change it for your own purpose. 
The enterprise mode uses Google Firebase Database as NoSQL database. You will have to change the Google Firebase schema to work on this mode, but easy to implm,ent. Watch a video on Firebase implementation. In both mode, GPT 4o implements Retrieval Augmented Generation based Agentic AI to record your response in the logbook.
